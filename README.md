# Portfolio — Nicolas Pueyo Cazalis

Site vitrine personnel présentant mon profil, mon parcours et mes projets dans le cadre de ma reconversion vers le développement web, en recherche d'un contrat de professionnalisation.

## Aperçu

Site one-page en HTML/CSS/JavaScript pur (aucune dépendance, aucun framework), avec une navigation qui met en surbrillance la section actuellement visible au scroll.

Sections du site :

- **Accueil** — présentation rapide
- **À propos** — parcours et objectifs professionnels
- **Critères d'alternance** — type de contrat, rythme, durée, disponibilité, formation
- **Compétences** — technologies en apprentissage et compétences métier
- **Expériences** — expériences professionnelles détaillées
- **Projets** — projets réalisés ou en cours
- **Contact** — email et téléphone

## Structure du projet

```
portfolio/
├── index.html   # Structure et contenu du site
├── style.css    # Mise en forme (thème sombre/clair, mise en page des sections)
└── script.js    # Surbrillance du lien de navigation actif au scroll
```

## Technologies utilisées

- HTML5
- CSS3 (Flexbox)
- JavaScript vanilla (aucune librairie)

## Lancer le site en local

Aucune installation n'est nécessaire. Il suffit d'ouvrir `index.html` dans un navigateur, ou de lancer un petit serveur local, par exemple :

```bash
npx serve .
```

## Déploiement

Le site est statique et peut être hébergé tel quel sur GitHub Pages, Netlify, Vercel ou tout hébergeur de fichiers statiques.
